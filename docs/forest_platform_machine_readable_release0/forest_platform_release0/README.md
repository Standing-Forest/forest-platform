# Forest Platform Machine-Readable Specification Package — Release 0

This foundational package contains:

- Requirement registry
- ADR registry
- Permission registry
- Error-code registry
- OpenAPI 3.1 skeleton
- JSON Schema foundation
- Canonical domain-event envelope
- Drizzle schema foundation
- SQL migration foundation
- Traceability matrix
- Specification validation script

Run:

```bash
python scripts/validate_specifications.py
```

This is a foundation package, not the complete production contract set. Trust scoring, full finance, consent, evidence, stories, research, federation, and complete API operations still require approved canonical schemas.
